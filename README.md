# فكرة — صندوق أفكارك

تطبيق ويب بسيط لالتقاط الأفكار بالصوت أو الكتابة، وجدولتها في تقويمك.

**[افتح التطبيق](https://USERNAME.github.io/fikra/)**

## لماذا

الفكرة تأتيك وأنت تسوق أو في الطريق، ووقت التقاطها ثانيتان. أغلب تطبيقات الملاحظات تطلب منك أن تنظّم وأنت تلتقط — فتضيع الفكرة. هنا الالتقاط أولاً، والتنظيم بعده.

## المميزات

- التقاط بالصوت أو الكتابة
- جدولة الفكرة في تقويمك — يعمل مع تقويم آبل وقوقل وأوتلوك
- تمت · حذف · تصفية
- يعمل بدون إنترنت بعد تثبيته
- عربي بالكامل من اليمين لليسار
- يتبع سمة جهازك الفاتحة والداكنة

## الخصوصية

**أفكارك لا تغادر جهازك.** لا حساب، ولا خادم، ولا قاعدة بيانات، ولا تتبّع. البيانات محفوظة في متصفحك وحده — ولا أحد يطّلع عليها، ولا نحن. زر «تصدير نسخة» يعطيك ملفاً بأفكارك متى أردت.

## التثبيت على جهازك

**آيفون وآيباد:** افتح الرابط في سفاري ← زر المشاركة ← إضافة إلى الشاشة الرئيسية

**أندرويد:** افتح الرابط في كروم ← قائمة المتصفح ← تثبيت التطبيق

التثبيت ليس تزييناً: التطبيق المثبّت يحفظ بياناتك بشكل دائم ويعمل بدون إنترنت.
